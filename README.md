# ports-data

Payload files (split WebGL builds, videos, streaming assets) for the browser ports in
[dashiellbenton/ports](https://github.com/dashiellbenton/ports). Nothing here is a page: the
pages in `ports` load these files from jsDelivr, pinned to a commit
(`https://cdn.jsdelivr.net/gh/dashiellbenton/ports-data@<sha>/<game>/`).
This repo has no GitHub Pages site, so it is not bound by the 1 GB Pages limit.
